OURLY - MVP FEATURE LIST

Latest consolidated scope for Hackathon implementation

Version: 11 Sep 2026

Product core: AI relationship advisor that understands the partner/couple context, gives relationship advice, recommends experiences, turns ideas into actionable moments, and reinforces thoughtful habits.

Note: Rules marked “Proposed Hackathon rule” were defined during product discussion to make the MVP implementable and should be treated as the current working rule unless the team changes them.

| # | Feature | Purpose | UI / User Action | Business Rule / Validation / Dev Logic |
| --- | --- | --- | --- | --- |
| 1 | Partner Linking / Couple Profile | Link two user accounts into one couple so the system can use both users’ context. | • User A taps Invite Partner.<br>• Invite by code/link.<br>• User B accepts.<br>• Show connected state. | • Create one Couple Profile linking both user IDs.<br>• Each user keeps their own profile/check-in/signal data.<br>• Couple-level AI context can read both users’ data. |
| 2 | Partner Profile | Create a partner profile so AI understands preferences and relationship context. | • Select relationship.<br>• Select preference tags.<br>• Select occasion and budget for current MVP flow.<br>• Save/Edit profile. | • Relationship: Boyfriend / Girlfriend.<br>• Validation from current scope: at least 2 preference selections + 1 occasion + 1 budget.<br>• Preference option catalogue is defined in the separate Preference & Selection Options document. |
| 3 | Partner Memory | Store small personal facts about the partner for long-term personalization. | • + Add Memory.<br>• Choose Type and enter Value.<br>• Edit/Delete memory. | • Memory = Type + Value.<br>• Allow multiple values under the same type, e.g. Favorite food = Sushi and Cheesecake.<br>• Types: Favorite food, Favorite drink, Favorite flower, Favorite place, Hobby. |
| 4 | Daily / Quick Check-in | Capture the user’s current emotion and need so partner and AI can understand today’s context. | • Choose 1 Emotion.<br>• Choose 1 Need.<br>• Submit or Skip. | • If submitted: 1 emotion + 1 need required.<br>• User may skip the daily check-in.<br>• Latest check-in can be included in AI context. |

| 6 | AI Love Advisor / Relationship Coach Chatbot | Core AI “love advisor”: user can vent, ask for relationship advice, ask what to say/do, or ask how to make the partner happy. | • Free-text chat.<br>• Quick prompts.<br>• AI gives advice.<br>• If advice is actionable, show “Turn this into a moment”. | • AI context may include Partner Profile + Partner Memory + latest Check-in + current chat context.<br>• The chatbot is not only a date generator; it is a relationship advisor.<br>• Quick prompts include: What should I do for her today? / Help me create a surprise / What should I say? / We have not dated in a while / She is sad. |

| 12 | Moment Feedback | Capture simple feedback after a completed moment so AI can learn. | • Choose one quick emoji feedback option. | • One feedback per completed moment.<br>• Store for future personalization/recommendation. |

| 15 | Achievement - Little Things Matter | Reward the first consistency milestone. | • Show unlock celebration and badge. | • Proposed Hackathon rule: unlock at 7-day Love Streak. |
| 16 | Achievement - Thoughtful Partner | Reward sustained consistency. | • Show badge in achievement area. | • Proposed Hackathon rule: unlock at 14-day Love Streak. |
| 17 | Achievement - Date Master | Reward completed experiences. | • Unlock after qualifying completion count. | • Proposed Hackathon rule: unlock at 3 Completed Moments.<br>• Suggested/Planned moments do not count. |
| 18 | Achievement - Boyfriend of the Year | Highest MVP badge and final demo WOW moment. | • Full-screen celebration.<br>• Show premium badge. | • Proposed Hackathon rule: unlock at 30-day Love Streak.<br>• Hackathon demo may use seeded data at day 29, then today’s qualifying action unlocks day 30. |
| 19 | Upcoming Occasion Notification | Proactively remind user about important upcoming occasions. | • Notification -> tap -> open AI Love Advisor with context. | • Proposed Hackathon rule: send at T-7 days and T-1 day.<br>• Each reminder sends once per occasion. |

| 21 | Streak At Risk Notification | Warn user before the current Love Streak is lost. | • Notification -> AI Love Advisor with Check-in / Signal / Plan suggestions. | • Proposed Hackathon rule: send once near end of day if streak is active but no qualifying action exists today.<br>• Maximum once per day. |
| 22 | Notification Priority | Avoid notification spam when several triggers happen together. | • Show only the highest-priority proactive notification. | • Proposed Hackathon priority: Upcoming Occasion -> Streak At Risk -> 7 Days Without Date.<br>• Proposed Hackathon limit: max 1 proactive Love Advisor notification/day. |
| 23 | Place Data / Tagging | Provide structured curated data for reliable recommendations. | • No admin UI required for MVP. | • Curated dataset: about 30-50 Da Nang places.<br>• Types: Restaurant / Cafe / Hotel / Activity.<br>• Attributes: id, name, image, location, budget, opening time, tags.<br>• Core tags: Romantic, Dessert, Beach, Quiet, Cozy, Outdoor, Photography. |
| 24 | Home / Couple Dashboard | Give one clear starting point for the relationship experience and proactive AI support. | • Show partner/couple context.<br>• Show upcoming occasion or AI suggestion.<br>• Quick actions: Ask Ourly / Plan a Moment / Check-in / Send Signal. | • Proposed UX rule: proactive AI suggestion is higher priority than a generic search box.<br>• Home should communicate that Ourly is a relationship advisor, not a restaurant directory. |

AI Love Advisor - implementation context

• Primary role: relationship coach / “love advisor” that helps the user understand what to say, what to do, and how to respond to relationship situations.

• Context available to AI: Partner Profile + Partner Memory + latest Check-in + current conversation context; recommendation flows may additionally use occasion, budget and curated Place Data.

• Action bridge: AI advice may end with “Turn this into a moment” to enter Recommendation -> Perfect Moment flow.
